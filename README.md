# Ignacio Fuentes · Porfolio de Growth y Producto

Porfolio estático en español. El contenido se edita en `index.html` y los estilos en `styles.css`.

## Vista previa local

Abre `index.html` en el navegador o ejecuta `python3 -m http.server 8000` desde esta carpeta y abre http://localhost:8000.

## GitHub y Vercel

1. Sube los archivos de esta carpeta a la raíz de un repositorio de GitHub.
2. Importa ese repositorio en Vercel como proyecto estático con el preset Other.
3. Deja vacíos el comando de compilación y el directorio de salida para servir los archivos desde la raíz.

## Antes de publicar

- Añade el enlace de LinkedIn o el correo profesional que quieras mostrar.
- Si tienes autorización para divulgar cifras internas, incorpora el periodo y la definición de cada métrica. Para onboarding, añade el resultado posterior a los cambios si lo tienes. Distingue tu contribución del resultado del equipo.
- En las automatizaciones, puedes añadir un ejemplo anonimizado de entrada y salida que puedas enseñar en entrevista.
